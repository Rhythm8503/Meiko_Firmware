# FFCosplays & Su Yin Sama Meiko Bracelets Firmware
This firmware was designed by Taheemuddin Ahmed (FFCosplays) for Su Yin Sama, this is for the Meiko bracelets. These bracelets have been customed designed for Su Yin Sama being a 1 of 1 piece. The firmware is designed to run on an ESP32-C3 inside FFCosplays custom PCB. 

---

# Features!
+ Rechargable Lithium Ion Battery via USB-C
+ Motion Dection utilizing ADXL345 Accelerometer
+ Bluetooth Connectivity through ESP32-C3 for LED, Behavior and etc.
+ Stereo Speaker setup through a custom designed circuit and PAM8403D Class D amplifier
+ AudioFFT LED Matrix, turning music into animations!
